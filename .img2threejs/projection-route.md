# Projection route decision

**Projection: not required. Skipped.**

Reason: this build follows `character/reconstruction.md`'s stylized/freehand track, confirmed at
the reference-suitability gate (`character-conditional -> stylized`), not
`likeness_maximization.md`'s projection-first track. The explicit, user-approved direction is a
low-poly faceted head built from flat color planes in the site's own acetate palette
(indigo/sienna/amber/ink), not the photo's own projected pixels — camera-matched photo projection
would be actively wrong for this target, since the whole point is to replace photographic albedo
with a small set of flat, named plane colors. Materials are authored per-component from the
image-analysis/detail-inventory observations (real colors sampled and mapped to the palette), not
baked from a projected, de-lit photo.
