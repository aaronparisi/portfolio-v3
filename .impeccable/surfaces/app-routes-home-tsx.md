## Direction contract

THESIS: The site is staged as a teacher's overhead-projector build-up demo — Aaron's hero portrait assembles live from a stack of acetate overlay transparencies, each one flat plane of real color derived from his own photo, refusing the standard "photo in a rounded card" hero template.

OWN-WORLD: Warm classroom-dark ground (near-black, warm-neutral, not pure black) under a soft amber projector light-cone (the dominant atmospheric field, not a flat accent swatch). Portrait rebuilt as 4-5 named flat ink planes (shadow / midtone / highlight / line / one warm accent), posterized in real code from the actual photo's own pixel data — a genuine derived matte, never a CSS mask. Geometric grotesk sans for display type, a sparing grease-pencil hand face reserved for annotation marks only, JetBrains Mono kept for code. No eyebrows anywhere on the site — removed sitewide, headline alone carries each section.

STORY: A visitor lands in a dim room lit by a projector already on; transparency sheets drop into place assembling Aaron's actual portrait before any copy is read — "this person builds things, precisely, layer by layer." Scrolling advances the story like changing slides: each section is a new transparency laid onto the platen.

FIRST VIEWPORT: Full-bleed dark ground, warm radial light-cone upper field, the assembling acetate portrait under it (this exact slot is what the future img2threejs 3D model replaces, per the user's explicit placement choice). Headline beside the portrait, not centered-over-dark-mesh, 2 lines max, no eyebrow. The existing integral-to-code hand animation persists as another grease-penciled overlay sheet in the same stack — the calculus-to-code mechanism is kept, re-staged, not discarded.

FORM: Assigned direction, fused per the user's explicit request to combine the Overhead-Projector world with the Recomposed-Portrait plane mechanism, resolved through the real classroom artifact of layered acetate overlays. Seed key 24682a12 (assigned index 4), donation from the dealt Tanaka plane-portrait challenger folded in as the user's fusion request rather than a raise.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
